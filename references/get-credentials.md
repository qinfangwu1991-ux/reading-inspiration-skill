# 用户需要做什么（按知识库）

> 原则：**能自动的全自动，用户只在必须时动手一次。** 这份文件是给用户在对话里直接看的，
> 不要在用户还没选知识库时全量贴给他。

## 先让用户知道：这些都不用他做

| 事情 | 谁做 |
|---|---|
| 建「读书灵感」文件夹 | 脚本 / 自动 |
| 建目录地图页 | 脚本 / 自动 |
| 找 Obsidian 笔记库路径 | 脚本自动扫（`setup.py detect obsidian`） |
| 取飞书租户域名、落库文件夹 | 脚本自动 |
| 乐享授权 | 对话内点一次「同意」，不用去后台 |
| 飞书授权（有连接器时） | 对话内点一次「同意」，不用建应用 |
| 记笔记、归类、写地图 | 全自动 |

---

## 乐享知识库：0 操作

用户只需要在你问「存到哪」时选乐享。剩下的（个人知识库定位、建文件夹、建索引页、落配置）全部由你在对话内完成。

如果乐享连接器还没授权，会直接弹一个授权确认，用户点同意即可 —— **不要让他去什么网站申请 Token**。

## 本地 Obsidian：0 操作

脚本会自动扫描本机所有 vault。用户要做的只有：如果他电脑上有多个笔记库，回一句「第 2 个」。

（只有当自动探测不到时，才让他提供：打开 Obsidian 随便一篇笔记右键 →「在文件管理器中显示」，把地址栏路径发来。）

## 飞书：两条路，看哪条通

### 有飞书连接器时：0 粘贴

对话里的飞书连接器能直接写云文档和知识库。用户只需要点一次「同意授权」——
**不要**让他去开放平台建应用，也别要 App ID。

> 注意：连接器入口在部分客户端里不显示（推荐卡片可能收不到）。如果用户说「没看到」，
> **立刻改走下面那条**，别让他反复找入口。

### 没有连接器（或找不到入口）时：粘贴两段字符

这条路的每个环节都实测过，稳。凭证只能由用户从开放平台复制一次，给他下面三步，链接直给：

1. 打开 https://open.feishu.cn/app → **创建企业自建应用** → 名字随意（如「读书灵感」）
2. 应用页左侧 **凭证与基础信息** → 复制 **App ID** 和 **App Secret**，两段一起发过来
3. 左侧 **权限管理** 勾选这两项：
   - `drive:drive`（查看、编辑和管理云空间中的文件）
   - `docs:document.media:upload`（上传文档素材）

   然后左侧 **版本管理与发布** → 创建版本 → **发布**（⭐ 不发布权限不生效，最常见的卡点）

发完这两段就到手了，文件夹和落库位置由脚本自建。

> 想让飞书也归档进**知识库**（而不只是应用云空间）：给他一个知识库链接
> （`https://<域名>/wiki/space/<space_id>` 形式）即可，脚本自动建索引页。
> 若提示建不成，原因是**应用需要被加成该知识库成员/页面协作者**，一句说清就行 —— 并且要明确告诉他
> 「云空间文件夹已经能用，不接知识库也能正常记录」。

## IMA：手机端才有

桌面会话里不存在 `mobile_ima_*` 工具。不要把它列进选项，也不要在 `kb_types` 里启用。
用户主动问起时再说明：手机端保存时会多一条 IMA，桌面端跳过。
